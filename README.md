# Foliant

Книжный каталог и личная библиотека на **Next.js 16 App Router** + **React 19** + **Tailwind CSS v4** + **Supabase**.

Приложение для поиска книг, ведения личных книжных полок, отслеживания прогресса чтения и обмена рецензиями.  Данные о книгах берутся из [Open Library API](https://openlibrary.org/developers/api), а пользовательские данные хранятся в **Supabase**.

---

## Стек

- **Next.js 16** (App Router, Turbopack)
- **React 19**
- **TypeScript 5**
- **Tailwind CSS 4**
- **Supabase** (аутентификация + PostgreSQL)
- **Framer Motion** — анимации
- **Lucide React** — иконки

---

## Функциональность

| Раздел | Что работает |
| ------ | ------------ |
| **Главная** | Hero-баннер + блок «Популярное сейчас» из каталога |
| **Каталог** | Поиск по названию, фильтры по жанрам, пагинация, пошаговая анимация загрузки карточек. Данные — Open Library |
| **Страница книги** | Slug-страница `/book/:id` с обложкой, описанием, метаданными, похожими книгами и кнопкой «Читать» |
| **Авторизация** | Регистрация / вход / выход через Supabase. В шапке отображается меню пользователя |
| **Профиль** | Страница `/profile/:id` с виджетами: статистика, цель на год, ударный режим, любимые жанры, текущая книга, высокие оценки, лента активности |
| **Личная полка** | Сохранение книг в статусы `want_to_read`, `reading`, `finished`, `dropped` в Supabase |
| **Прогресс чтения** | Таблица `reading_progress` для отслеживания процента прочтения |

---

## Архитектура БД

Основные таблицы Supabase:

- `profiles` — профили пользователей.
- `follows` — подписки между пользователями.
- `books` — кэш метаданных книг из Open Library.
- `user_books` — книги пользователя со статусом, рейтингом и отзывом.
- `reading_progress` — прогресс чтения по каждой книге.

---

## Текущая стадия

Реализованы базовый каталог, авторизация, профиль пользователя и первая итерация личной полки. Книги можно добавлять в статус «Читаю» прямо со страницы книги, и они отображаются в профиле в блоке «Читаю сейчас».

Последние изменения:

- добавлены таблицы `books`, `user_books` и `reading_progress`;
- реализованы заглушки и серверные экшены для профильных виджетов;
- блок «Читаю сейчас» связан с реальными данными из Supabase;
- добавлена пошаговая анимация появления карточек в каталоге;
- обновлены типы данных под новые таблицы.

## Локальный запуск

1. Скопируй `.env.example` в `.env.local` и заполни переменные Supabase.
2. Установи зависимости:

   ```bash
   npm install
   ```

3. Примени миграции Supabase (через CLI или SQL Editor в Dashboard).
4. Запусти dev-сервер:

   ```bash
   npm run dev
   ```
